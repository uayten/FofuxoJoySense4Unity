# Fofuxo's JoySense4Unity

**English** (in development) · [Português](README.pt-BR.md)

The Unity counterpart of [JoyShockLibrary4Unreal](https://github.com/AgentOttsel/JoyShockLibrary4Unreal):
native support for Sony and Nintendo controllers in Unity's Input System, starting with the
**Nintendo Switch 2 Pro Controller over USB**.

The English documentation is in development.
